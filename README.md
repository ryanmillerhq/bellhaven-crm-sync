# Bellhaven CRM Sync

Keeps facility → parent-company ownership accurate in a CRM. A daily pipeline scrapes an operator's website
(Bellhaven Senior Living, a fictional operator), matches each community to CRM accounts, and queues proposed fixes with
evidence. A reviewer approves or rejects each one in a small web app, and only approved changes are written back to
the CRM.

Built as the Clipboard Health Sales Operations Analyst take-home exercise.
